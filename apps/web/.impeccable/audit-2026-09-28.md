# UI/UX + accessibility audit of apps/web (2026-09-28, code read, pre-redesign)

Paths are relative to `apps/web/src`. Contrast ratios computed from the old tokens.

## Cross-cutting
- **Contrast failures:**
  - primary-300 (#588157) with primary-50 text, 4.18:1: every PillButton and "View" button.
  - Danger buttons, white on #ff5353: 3.17:1.
  - WhatsApp buttons, white on #25d366: 1.98:1.
  - Grey text:
    - neutral-500 #adb5bd on white: 2.07:1.
    - #9da4ab on primary-100: 2.16:1.
    - Placeholders at rgba(51,51,51,.5): 2.85:1.
    - ink-subtle #898989: 3.5:1.
  - The sidebar "Soon" label: 2.89:1.
  - The primary-200 focus ring: 1.4:1.
- **Focus:** there are no `focus-visible` styles, and the gallery search removes the outline (`galleries-view.tsx:45`).
- **Titles and navigation:** every page has the same `<title>`, and there is no skip link.
- **Reduced motion:** honored only in the workflow timeline.
- **Language switch:** labels are inconsistent ("عربي/Eng" vs "العربية/English") and have no `lang` attribute.
- **Hard-coded English:** "Close menu", "Close" and "X" in the dialog, and "EGP".
- **Numbers:** Arabic mixes digit systems where numbers skip `format.number`.
- **Status colors:** copy-pasted in 3 files.

## Marketing homepage
- **Mobile:** there is no mobile nav (`site-header.tsx:15`, `hidden md:flex`). The language link is about 20px tall.
- **Copy:** "Start Free Trial" links to /apply, but the product is invite-only and that page says Request access.
- **Contrast:**
  - Inactive timeline text is about 3.5:1.
  - The translucent trial button over the photo is about 2.6:1.
  - White nav text sits over the photo with a weak tint.
- **Type:** `font-extrabold` renders without weight 800 loaded.
- **Layout:** `pb-[300px]` is coupled to `-mt-[280px]` in the Why section, and there are many arbitrary sizes and hex values. `dir=ltr` on prices breaks the Arabic order.

## Auth (login, apply, forgot-password, invite)
- **Critical: placeholder-only labels** (`fields.tsx:20-25`). Disabled invite fields show no label at all. Edit Gallery reuses the same field.
- **Errors:** field errors are not announced and do not move focus. The checkbox error and the password hint are not linked with aria-describedby.
- **Forgot password:** changing step does not move focus, and "Resend" has no cooldown or pending state.
- **Other:**
  - No language switch on auth pages.
  - The brand nav has no label.
  - The checkbox is 16px.
  - Decorative art uses physical `left`.
  - The invite skeleton has no text.
- **Styling:** the SubmitButton is square and uses a bluish #e9f4ff text color, unlike the rest of the app.

## Photographer app shell, dashboard, galleries
- **Critical: the mobile drawer** has role=dialog, but focus never moves in, Escape does nothing and the background is not inert (`app-shell.tsx:26-33`).
- **Account menu:** uses role=menu without keyboard support or Escape, and the disabled item is unfocusable (`app-header.tsx`).
- **Headings:** the dashboard has no `<h1>`, and card titles are `<p>`.
- **Error states:** a failed galleries query shows "No galleries yet", and a failed dashboard query leaves the skeleton spinning forever.
- **Table:** `min-w-[1000px]` with 12px text scrolls sideways on phones and tablets. The "No" column and 01/02 row numbers are meaningless.
- **Copy link:** has no error handling, and its only feedback is a title tooltip.
- **Sidebar and actions:** "Soon" items (Clients, Notifications, Settings) are dead nav entries. "Edit profile" is disabled. "Upload New Project" duplicates Create Gallery.
- **Other:**
  - Progress bars have no accessible name.
  - The language switch is hidden below `sm`.
  - Touch targets are 32–36px.

## Gallery detail
- **Destructive actions:** `window.confirm` is used for folder delete and file delete.
- **Error handling:**
  - Delete gallery has none.
  - "New password" has no confirmation and no error handling, even though it breaks the password the client already has.
  - A non-404 load error leaves the skeleton spinning forever.
- **Upload panel:** `aria-live` wraps the whole panel, so screen readers announce every byte update.
- **Media grid:** the rejection reason is only in a title tooltip.
- **Headings:** the h1 is the generic "Gallery Data" instead of the gallery's name.
- **Inconsistent forms:** Create uses rounded fields with labels, while Edit uses square placeholder-only fields for the same data.
- **Colors:** Share uses an off-palette blue (#5053ff, #0003CA).
- **Layout:** fixed widths (140px label column, 208px buttons). Section h2s are grey `text-lg`.
- **Small targets:**
  - Back link: 24px.
  - Folder delete: 32px.
  - File delete: 28px.
  - Dialog X: about 24px.
- **Markup:** a `<span>` sits inside `<dl>`.

## Billing
- **Popups:** invoice and receipt use `window.open` after an `await`, which popup blockers stop. The receipt has no error handling.
- **Destructive actions:** cancel payment uses `window.confirm`.
- **Keyboard:**
  - The payment-method tablist has no arrow keys, no aria-controls and no tabpanel label.
  - The cycle radiogroup has no roving focus.
- **Flow:** checkout creates a payment immediately with no review step.
- **Errors and loading:** proof errors are not linked to their fields, and loading is plain text.
- **Other:** the small copy button is about 24px. Colors #9da4ab, #6d747b and #fff8eb are hard-coded.

## Client gallery (g/[token])
- **Critical: the viewer** has no focus trap, and the page behind it is still focusable (`viewer.tsx:168`).
- **Critical: Escape in download-all** closes the native dialog while React state stays open. Progress is lost and the dialog cannot be reopened.
- **Loading:** the spinner has `role=status` but no text.
- **WhatsApp outline icon:** about 1.4:1 contrast.
- **Viewer controls:** prev and next are hidden on mobile, and zoom has no keyboard control.
- **Folder tabs:** use `aria-current` where `aria-pressed` fits.
- **Download all:** disabled with no reason given.
- **Errors:** report and unlock errors are not linked with aria-describedby.
- **Small targets:** the language toggle is about 32px and the show/hide toggle is 36px.
- **Colors:** #fbfaf7, #fff8eb, #f5c77e and #ffd98a are hard-coded.

## Mismatches between surfaces
- The primary color differs by area: primary-400 on home, auth and client, but primary-300 in the app.
- **Buttons:** square on home and auth, rounded-3xl in the app, rounded-full in billing and client.
- **Inputs:** square, 23px, rounded-xl and rounded-full in different places.
- **h1 styles:** four different ones.
- **Text on primary:** three different "on-primary" colors.
- **Header surfaces:** three different backgrounds.
- **Icons:** non-square artboards with hard-coded fills.
- **Type:** 29 distinct font sizes.
- **Radii:** 18 variants.
- **Control heights:** 36, 40, 42, 44, 48, 52, 53 and 60px, with no scale.
